## Q1：为上位机学习 C#，到 TASK-008 为止，基础是否差不多结束了？

- 状态：待复习
- 日期：2026-10-05
- 关联：[计划原文](../plan.md)、[学习进度](../learning.md)、[TASK-008](../tasks/TASK-008.md)、[TASK-009](../tasks/TASK-009.md)。

你当时问“TASK-008 做完，是否可以进入界面开发”。根据已验证的设备模型、事件、集合查询、异步读取、取消、JSON 和接口练习，已经可以开始 WPF；不需要先学完 C# 的所有语法再写一个窗口。

这个选择来自 [计划原文](../plan.md) 的顺序：第一阶段 C# 基础，第二阶段 WPF。已有 Java 后端背景可以帮助迁移部分经验，但不能据此默认你会 XAML、按钮、布局或桌面线程问题。

例如进入 WPF 后，真实窗口需要“按钮点下去做什么”和“读到的数据怎样显示”。于是属性、事件、异步继续在这些具体问题里补充，而不是为每个待复习名词另设考试。TASK-009 是当时的下一步；现在 TASK-009～019 已通关，TASK-020 进行中，进度以 [learning.md](../learning.md) 为准。

任务级通关确认的是该次要求和证据；完整属性、委托机制、线程和资源释放仍有复习内容，所以不能宣布 C# 或 WPF 阶段整体已掌握。后续通信、采集和设备控制按原计划与真实实践逐步推进，不在本次整理中另建任务。

按当前计划已经明确的第三阶段串口目标，预计TASK-044通关之后再安排3至4个完整实践任务，而不是再把字段、判断或方法调用分别拆题；这是根据剩余目标作出的估算，不是已经创建的任务或保证的通关数量。
剩余工作可以围绕三个完整结果推进：串口读数接入新WPF窗口与历史/曲线/报警；通信异常与停止关闭后的正确收尾，包括超时、断开、重连及窗口关闭；按明确协议完善适用的数据检查和坏数据恢复，并完成从接收到显示的综合联调。
综合联调通常与上述实践合并验收，若实际问题需要独立整合或巩固，则预计增加为4个；不为了凑数量漏掉阶段目标，也不把新增小知识自动变成新任务。
TASK-044已包含端口打开、发送、接收、基本解析和关闭重开，后续复用这些成果，避免重复安排同样的前置练习；校验和长度规则只在协议明确且适用时要求，不把当前六字节教学帧的最后一个字节擅自当作校验。
