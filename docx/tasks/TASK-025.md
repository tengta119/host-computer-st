在构造方法的TODO 1a处登记：

```csharp
_temperatures.CollectionChanged += Temperatures_CollectionChanged;
```

在Temperatures_CollectionChanged的TODO 1b处写：

```csharp
ReadingCountText.Text = "完整历史条数：" + _temperatures.Count;
```

_temperatures指向本窗口保存原始温度的集合；CollectionChanged是.NET集合自带的事件。+=是C#登记方法的写法，右侧是教练新建的普通方法名，不带括号，所以这行只建立“集合变了就调用它”的关系，不立即执行。Count是集合当前实际条数；ReadingCountText是XAML里的文字控件，Text是WPF属性，赋值后它显示拼出的文字。

## 使用前必须先解释

1. 指向“添加下一条”按钮：它的Click方法往同一集合Add一条温度；集合变化后，原折线不会仅因集合叫ObservableCollection就自动收到新的Points。
2. 先用已有Add/Clear解释集合的CollectionChanged事件：谁发通知、哪个普通方法接收、订阅语句如何连接。委托/event来源与基础仍待复习，必须先给完整普通写法，不能只要求“订阅事件”。
3. 首步只在集合变化处理方法显示Count。新增后数字增加、清空变0，再推进绘图，不一次要求完成所有连接。
4. 画最新三条时，先用四条24/26.5/25/28说明为什么取后面26.5/25/28；用普通if/for拆开起始下标和槽位位置，不依赖未解释的LINQ或切片简写。
5. 明确数组/集合保存温度、PointCollection保存坐标、Polyline.Points接坐标；空集合时也要交给蓝线空的坐标集合，不能早退而留下旧线。
