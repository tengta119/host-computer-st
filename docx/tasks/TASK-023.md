## 场景与目标

建立独立双栏窗口：左栏放设备下拉框、读取/清空按钮和状态提示，右栏放历史标题与三列只读表格。左栏根据现有控件所需宽度安排，右栏取得剩余宽度；窗口拉宽时表格变宽，拉高时表格变高。复用同一份原 ViewModel、集合、命令与 Binding，不新增通信、自动采集或新数据框架。

本题向计划的设备监控界面布局推进一小步；当前三列温度历史不是完整设备监控系统，不认定 WPF 阶段整体完成。完整界面设计、图表换算/实时更新及 C# 基础机制继续按原记录复习。

## 开始前必须先解释

1. 指向主窗口的左操作区和右历史区：Grid.ColumnDefinitions 给主 Grid 分列，ColumnDefinition 描述每列的宽度；先解释当前具体区域，再要求配置。
2. Width=Auto 让左栏按下拉框、按钮和间距所需宽度安排；本题仅一个星号列时，Width=* 把剩余宽度交给右栏。用窗口实际拉宽的预期说明，不因已做行布局就默认列布局已会。
3. Grid.Column=0/1 指定整块区域所在列；右历史区内标题/表格仍按原两行摆放，两层 Grid 分别安排不同对象。
4. 表格固定 Width/Height 会限制增长；保留原数据连接，外层布局直接取得窗口有限空间。骨架已有属性/名字分别交代来源。
