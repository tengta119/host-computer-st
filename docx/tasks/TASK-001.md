## 场景与学习目标

用一个小型设备读数例子练习 C# 类型、类、泛型集合和简单业务判断，把熟悉的 Java 写法迁移到 C#；不要求此时实现真实设备通信或 WPF 界面。

## 核心知识点

- C# 类、属性/方法与基本类型；与 Java 的相同点和差异。
- `List<T>`、`Dictionary<TKey,TValue>` 的使用。
- 将设备数据转成可读输出；对异常或缺失输入做基本处理。
