# 学习路线

## Q1：为上位机学习 C#，到 TASK-008 为止，基础是否差不多结束了？

- 状态：待复习
- 日期：2026-10-05
- 关联：[计划原文](../plan.md)、[学习进度](../learning.md)、[TASK-008](../tasks/TASK-008.md)、[TASK-009](../tasks/TASK-009.md)。
- 现象：TASK-001～008 已通过任务级验收，学员询问是否可以结束集中学习 C# 基础并进入上位机界面开发。
- 原因与依据：现有实践已涉及设备模型与集合、委托/事件、Lambda/LINQ、Task/async/await、取消、JSON 配置、接口与多态，覆盖计划中进入 WPF 前的主要主题。计划明确以 Java 后端经验迁移为起点，无须先穷尽 C# 语法才能写窗口。
- 判断：已具备开始 WPF 起步练习的基础，C# 基础的集中入门可以先告一段落；任务级通关不等于熟练掌握所有语言机制，也不等于能够独立完成稳定的上位机项目。
- 实践衔接：在 WPF 中继续巩固属性、事件和异步，随后按计划学习通信、采集与设备控制。Task/线程、属性、可空类型及资源释放按真实问题继续补充，不把待复习问答当作进入 WPF 前的单独考试。
- 类比：已有 Java 背景时，学习 C# 可以先掌握完成当前功能所需的语言用法，再通过界面和设备项目逐步熟练。
- 总结与复查点：可以推进 TASK-009，C# 学习继续贯穿上位机实践；阶段仍有待复习内容，当前不标第一阶段整体已通关。本轮只答疑与记录，未开始 TASK-009、未新增任务或运行代码。
