## 发现：整数除法丢失小数，且没有单独输出原始数值

位置：Task044Exercise.cs第167至169行，PrintReading方法。

```csharp
byte id = frame[1];
int value = (frame[3] * 256 + frame[4]) / 10;
Console.WriteLine("设备Id:" + id + "," + "Value:" + value.ToString("F1"));
```

frame[3]与frame[4]合成整数的顺序正确，但随后除数10也是整数，C#会先做整数除法；按语言规则推导，01 00对应256，256 / 10得到25，而不是本题要求的25.6。
对已经变为25的int调用ToString("F1")只改变显示形式，不能恢复被整数除法丢掉的小数；此处25.0是源码语义推导，不是本轮运行结果。
当前value同时混用了原始值与温度两个含义，输出只显示设备编号和一个换算值，没有单独显示任务要求的原始数值256。
修复线索：先用int变量保留两个字节合成的原始值，再用double变量保存原始值除以10.0得到的温度，输出编号、原始值和温度三项，一位小数格式只用于温度显示；核心修改留给学员。
